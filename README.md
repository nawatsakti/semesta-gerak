# Semesta Gerak V5 — Custom Universe

Fitur:
- Galaxy interaktif + hand tracking
- Name Constellation
- Shape Morph preset: Heart, Butterfly, DNA, Code, Logo Informatika
- CUSTOM: ketik teks/angka/emoji bebas
- CUSTOM: upload PNG/JPG/WebP/logo dari perangkat
- CUSTOM: gambar sendiri dengan mouse/jari lalu ubah jadi partikel
- Capture Moment ke PNG
- Idle / Attraction Mode untuk pameran
- Tahan 2 tangan ±2 detik untuk Logo Reveal

## Jalankan di Windows
Buka CMD di folder ini lalu:

```cmd
npm install
npm run dev
```

Buka `http://localhost:5173`

Shortcut: N Nama, B Bentuk, S Capture, F Fullscreen, R Reset, C Kamera.
